# Connect Four Game

A Java console-based Connect Four game developed during my Java programming internship.

## Technologies Used

- Java
- Object-Oriented Programming
- Console-based input and output

## Features

- Connect Four board-based gameplay
- Player input handling
- Column selection from 1 to 7
- Validation for invalid inputs
- Validation for full columns
- Player name, symbol, and score management
- Separate classes for game, board, players, and input validation

## Project Structure

- `ConnectFour.java` - Main Connect Four application
- `Game.java` - Game-related functionality
- `GameBoard.java` - Game board management
- `Player.java` - Base player abstraction
- `HumanPlayer.java` - Human player implementation
- `ComputerPlayer.java` - Computer player implementation
- `Playable.java` - Playable game interface
- `InputValidator.java` - User input validation
- `FileManager.java` - File-related operations

## Concepts Practiced

- Classes and Objects
- Abstraction
- Inheritance
- Encapsulation
- Polymorphism
- Interfaces
- Exception Handling
- Modular Programming

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA or VS Code.
3. Compile the Java source files.
4. Run the main class to start the game.
